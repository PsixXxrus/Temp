СНГБ Онлайн Бизнес · PayControl

Работа с PayControl
в «СНГБ Онлайн Бизнес»

Инструкция по добавлению и настройке ключа PayControl в отдельном приложении PayControl и в мобильном приложении «СНГБ Онлайн Бизнес».

Введение

Система дистанционного банковского обслуживания (далее – ДБО) «СНГБ Онлайн Бизнес» для малого и среднего бизнеса (далее - система) предназначена для передачи от клиента в банк и обратно платежных и иных документов по электронным каналам связи.

Документ рекомендуется использовать и в качестве ознакомительного материала, и в качестве справочника при работе с системой. Документ рекомендован как для последовательного, так и для выборочного чтения.

Предполагается наличие у пользователя базовых знаний в области банковского обслуживания и банковской документации.

Предполагается также, что пользователь обладает практическими навыками работы с приложениями в операционной системе Mac OS и / или Windows, включая работу в сети Интернет с использованием веб-браузеров.

PayControl — программный комплекс, предназначенный для подтверждения пользователем операций в системах дистанционного банковского обслуживания и/или формирования подписи в системах электронного документооборота.

1

Ключ в приложении PayControl

Вариант 1. Ключ PayControl добавляется и используется в отдельном мобильном приложении PayControl.
1

Установите приложение PayControl

Необходимо загрузить приложение «PayControl» на мобильное устройство из:

  • AppStore
  • RuStore
  • Google play
  1. В зависимости от вашего устройства зайдите в один из указанных источников для скачивания приложения.
  2. В поисковой строке введите: «PayControl».
  3. Найдите приложение от разработчика: «SafeTech».
  4. Используйте кнопку «Установить», либо «Скачать». Для загрузки приложения на устройство.
2

Откройте PayControl

Когда приложение будет установлено – откройте его.

3

Разрешите отправку уведомлений

При первом запуске откроется информационное окно о разрешении на отправку уведомлений.

  • Для получений уведомлений об операциях разрешите приложению отправлять уведомления. Используйте кнопку «Разрешить».
  • Если вы нажали на «Не разрешать», то в настройках устройства найдите приложение и измените настройка для отправки уведомлений.
4

Перейдите к сканированию QR-кода

Для добавления ключа в приложение используйте кнопку «Сканировать QR» или кнопку «QR» в левом верхнем углу экрана.

5

Подготовьте QR-код ключа

Найдите QR-код, который Вам предоставил Банк для добавления ключа PayControl.

Обратите внимание: ключ будет привязан к устройству, на котором вы выполняете вышеперечисленные действия.
6

Отсканируйте QR-код

Приложение может потребовать доступ к камере устройства для сканирования QR-кода. Разрешите использование камеры.

Либо вы можете загрузить изображение QR-кода из галереи устройства, используйте кнопку сверху справа «4 квадрата» для открытия галереи. Отсканируйте/загрузите QR-код.

7

Укажите название ключа

После сканирования QR-код нужно указать название ключа (желательно использовать то название, которое будет отображать назначение ключа).

На рисунке указано НАЗВАНИЕ ОРГАНИЗАЦИИ как пример, что название ключа — это любой текст, который можете указать самостоятельно. После нажмите на кнопку «Далее» для перехода к следующему этапу.

8

Задайте пароль для ключа

В следующем этапе необходимо задать пароль для использования ключа. Это необходимо для безопасности использования ключа.

Рекомендация по безопасности: Мы не рекомендуем использовать лёгкие пароли, либо не использовать ключ без пароля.

Введите и подтвердите пароль. После нажмите на кнопку «Далее» для перехода к следующему этапу. Если пароли совпадают вы увидите уведомление «Готово».

9

Сгенерируйте данные для работы подписи

После настройки ключа требуется сгенерировать данные для работы подписи, для этого необходимо при появлении окна как на рис 2.9 нажимать на экран устройства в случайном порядке до заполнения шкалы (ниже текста «Нажимайте для генерации случайных данных»).

После заполнения шкалы ключ будет отображаться на главном экране в приложении PayControl.

Примечание: ключ «PayControl» может использоваться для прохождения двухфакторной аутентификации, подписания документа отправляемого в банк. Любые операции, требующие подтверждения могут быть обработы с использованием ключа «PayControl».
2

Ключ в мобильном приложении «СНГБ Онлайн Бизнес»

Вариант 2. Ключ PayControl добавляется непосредственно в мобильном приложении «СНГБ Онлайн Бизнес».
1

Запустите мобильное приложение

Запустите установленное мобильное приложение «СНГБ Онлайн Бизнес».

2

Авторизуйтесь

Авторизуйтесь под пользователем организации.

3

Перейдите к управлению ключами PayControl

Перейдите в меню для управления ключами PayControl.

4

Добавьте новый ключ

Нажмите на кнопку «Добавить ключ» и «Сканировать QR» для добавления нового ключа PayControl.

5

Отсканируйте QR-код

Отсканируйте QR-код выданный Банком. Если потребуется, то разрешите приложению использовать камеру мобильного устройства.

6

Введите код активации

После сканирования QR-кода необходимо ввести код активации ключа PayControl в поле «Введите код активации».

Код активации был отправлен на мобильное устройство ранее, когда был создан ключ.

7

Подтвердите информацию и сгенерируйте данные

После ввода кода появиться информации о ключе PayControl. Нажмите на кнопку «Продолжить».

После откроется окно по генерации случайных данных, в этом окне необходимо нажимать в случайные точки на экране, а полоса сверху будет заполняться. Дождитесь полного заполнения полосы сверху экрана, нажимай на экран устройства.

8

Выберите защиту и задайте название ключа

Когда полоса сверху заполнится полностью, то появится окно с выбором средства защиты ключа и название ключа.

Рекомендация по безопасности: Мы не рекомендуем использовать лёгкие пароли, либо не использовать ключ без пароля.

ООО «Тестируем вместе» как пример, что название ключа — это любой текст, который можете указать самостоятельно.

9

Ключ готов к использованию

Все этапы выполнены, и вы можете использовать свой ключ.
